# Kunskapsbas för nyttoanalyser

Detta repository innehåller Ineras kunskapsbas för nyttoanalyser.

Kunskapsbasen beskriver den metod som tidigare benämndes **Ineras metod för nyttokalkyler** och ligger till grund för den kommande **AI-assistenten för nyttoanalyser**.

Materialet publiceras här för att göra metoden och kunskapsbasen tillgängliga för användare och andra som vill ta del av dem.

## Aktuell version

**KB 06**

KB 06 är den version av kunskapsbasen som AI-assistenten för nyttoanalyser för närvarande bygger på.

Kunskapsbasen vidareutvecklas över tid. När en ny version publiceras uppdateras innehållet i repositoryt. Publicerade versioner bevaras genom GitHubs versionshistorik och kan märkas med taggar eller releases, så att det även i efterhand går att hänvisa till en specifik version.

## Så hittar du i kunskapsbasen

Dokumenten i repositoryt utgör tillsammans kunskapsbasen.

Det finns både:

- **översiktliga dokument**, som beskriver metodens syfte, struktur, principer och hur olika delar hänger ihop
- **metodspecifika dokument**, som innehåller mer detaljerade instruktioner och kunskap för olika delar av en nyttoanalys

För att få en övergripande förståelse för metoden rekommenderas att börja med de översiktliga dokumenten och därefter gå vidare till de metodspecifika dokument som är relevanta för den analys som ska genomföras.

När dokumenten finns i repositoryt kan denna README kompletteras med länkar till de viktigaste startpunkterna.

## Hur kunskapsbasen används

Kunskapsbasen är avsedd som stöd för att genomföra nyttoanalyser.

Dokumenten ska ses som delar av en sammanhängande kunskapsbas. De översiktliga dokumenten ger sammanhang och gemensamma principer, medan de metodspecifika dokumenten ger mer detaljerat stöd för olika moment i analysen.

Samma kunskapsbas används som grund för den kommande AI-assistenten för nyttoanalyser.

## Versioner och ändringar

Den aktuella versionen finns i repositoryts huvudgren (`main`).

### Vad innebär det?

Du får ta del av materialet och använda kunskapen, idéerna och metodprinciperna som stöd när du genomför egna nyttoanalyser.

Att materialet är publikt innebär däremot inte i sig ett generellt tillstånd att kopiera, bearbeta, återpublicera eller distribuera kunskapsbasens texter och andra upphovsrättsligt skyddade delar.

Om du vill återpublicera materialet, skapa och sprida en bearbetad version eller använda hela eller delar av kunskapsbasen på annat sätt som innebär kopiering eller vidarepublicering kan tillstånd från rättighetsinnehavaren behövas.

Inera utreder för närvarande vilken öppen licens som ska gälla för materialet. Avsikten är att villkoren för återanvändning ska bli tydligare. Informationen här kommer att uppdateras när licensfrågan är fastställd.

Vid frågor om användning av materialet kan du skapa ett Issue i detta repository eller kontakta ansvarig på Inera.
