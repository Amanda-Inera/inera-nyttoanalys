# Följ upp nyttor när förändringen genomförs

## Börja följa upp när förändringen börjar

Nyttoanalysen beskriver vilka nyttor som förväntas uppstå. När förändringen börjar genomföras kan du börja följa om utvecklingen går åt rätt håll.

Återkommande uppföljning kan visa när förändringsarbetet behöver justeras. Den ger också ett kvitto när förändringen börjar ge förväntade resultat.

## Följ upp att förändringen genomförs och används

För att nyttorna ska kunna uppstå behöver förändringen nå de berörda och användas i praktiken. Följ därför upp om förändringen har genomförts, om nya arbetssätt används och om de förutsättningar som nyttorna bygger på finns på plats.

Om genomförandet inte har kommit tillräckligt långt går det inte heller att förvänta sig att nyttorna har realiserats fullt ut.

## Följ upp nyttor eller effekter som leder till dem

Utgå från nyttorna och sambanden i nyttoanalysen. Följ nyttan direkt när det finns ett lämpligt sätt att göra det. Ibland är det lättare att följa en tidigare effekt i sambandet än den slutliga nyttan.

Om den förväntade nyttan exempelvis är ökad trygghet kan färre läkemedelsavvikelser vara en effekt som går att följa tidigare eller mer konkret. Effekten ger då information om utvecklingen, även om den inte ensam visar att tryggheten har ökat.

## Använd uppföljningen för att utveckla förändringen

Om effekterna eller nyttorna inte utvecklas som förväntat kan uppföljningen visa var förändringsarbetet behöver förstärkas eller justeras. Det kan handla om att förändringen inte används som tänkt eller att viktiga förutsättningar saknas.

När uppföljningen visar en positiv utveckling ger den samtidigt stöd för att fortsätta arbetet och behålla det som fungerar.
